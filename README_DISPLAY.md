# Time Pod — Desktop Display (Hacker Terminal UI)

Build:
```bash
make clean && make
```

Run:
```bash
./timepod
```

Controls while running:
- `1..6` start a domain timer
- `p` pause/resume
- `c` continue
- `q` quit

UI:
- Left panel shows active domain and remaining time
- Right panel shows a persistent per-day completion tick grid
